# HOSPITAL DEFENSE

架空の病院を守る、オフライン動作のサイバーセキュリティ・タワーディフェンスゲームです。**PC優先・スマホ対応**で、外部ライブラリやAPIを使用しません。

## 起動方法

1. フォルダ構造を保ったままダウンロードする。
2. ルートの `index.html` を Chrome または Edge で開く（サーバー不要）。
3. ショップを開いて設備を選択し、マップの丸い地点を直接クリック／タップして配置する。
4. ウェーブを開始して防衛し、SPを獲得してタワーや職員教育を強化する。
5. 診療継続度・情報保護度を守り、全5ウェーブのクリアを目指す。

## 主な機能

- メールフィルター／MFA／EDR／ネットワーク分離の4種の防御設備
- タワーの3段階強化・売却、SPの獲得と消費
- 新しい侵入ルート、突発的な人的リスク、職員教育による対処
- 事業継続策（BCP）、一時停止、2倍速、ログ、勝敗判定
- **ショップ・強化・職員教育・ログをボタンで開くスライドパネルUI**
- マップ上の直接設置・選択と、番号による補助操作

## ソース構成

```text
index.html           画面構造・ゲーム起動
css/styles.css       全体デザイン・レスポンシブ表示
css/drawer.css       スライドパネル表示
js/game-data.js      敵・タワー・ウェーブ・数値設定
js/app.js            描画・ゲーム進行・操作・勝敗判定
CHANGELOG.md         変更履歴
archive/             移行前の単一HTML版の保存
```

スクリプトは `game-data.js` → `app.js` の順に読み込んでください。

## 開発上の注意

- `file://` で開けるよう、ES Modules や `fetch()` は使用していません。
- GitHub Pages / Cloudflare Pages ではリポジトリのルートに `index.html` を置き、フォルダ構造を維持します。
- 既存の単一HTML版は `archive/2026-11-06-pre-modular.html` に保存しました。
- 履歴の詳細は [CHANGELOG.md](./CHANGELOG.md) および GitHub のコミット履歴を参照してください。

## 留意点

本ゲームは教育用のフィクションです。攻撃手順や実際の院内ネットワーク構成を再現したものではなく、ゲーム内のポイント・対策効果・発生確率は現実の効果や法令適合性を示しません。

## v3.1：仮配置とカバー範囲プレビュー

1. 空き地点（または補助の番号）を選択するとショップが開きます。
2. どの設備を置くか比較します（必要SP・Lv.1の射程を表示）。
3. 設備を選ぶとショップが閉じ、マップに円形の有効範囲が表示されます。
4. 「設置確定」を押すまでSPは消費されません。設備の変更・キャンセルも可能です。
5. 防衛中に仮配置する場合はゲームが自動一時停止し、処理完了後に元の状態に戻ります。

射程はゲーム内の相対距離（マップ座標）です。実際のネットワーク到達可能性を表すものではありません。

## v3.3：初心者チュートリアルモード

- ヘッダーの「🎓 チュートリアル」から操作練習を開始できます。通常モードと同じゲームを利用しますが、進行は練習専用です。
- 実際の操作を9段階（地点選択、メールフィルター選択、射程確認・設置、既存設備選択、設備強化、職員教育の表示・強化、ウェーブ開始、観察）で案内します。
- 正しい操作対象が点滅し、説明パネルに次の行動を表示します。
- 練習ウェーブは4件の仮想攻撃で構成され、終了後に「通常プレイへ」でゲームが初期化されます。
- 途中終了、やり直しに対応。練習中のSP・スコアは本編に引き継ぎません。
- 初回起動時の強制表示やブラウザ保存は行いません。個人情報・学習履歴は収集しません。
- 新規の `css/tutorial.css` にガイド表示のスタイルを分離しています。
