# HOSPITAL DEFENSE

架空の病院を守る、ブラウザで遊べるサイバーセキュリティ・タワーディフェンスです。**インストール・外部通信・サーバー不要**の単一HTML版です。

## 遊び方

1. `index.html` をダウンロードし、Chrome / Edge などのブラウザで開く。
2. 右側の設備ショップから防御タワーを選ぶ。
3. マップ上の丸い配置地点をクリック／タップして設置する（スマートフォンでは番号ボタンも利用可能）。
4. 「ウェーブ開始」で攻撃が進行する。防御成功でSPを獲得する。
5. 配置済みタワーをタップし、クイック強化欄からLv.3までアップグレードする。
6. 職員教育にSPを投資すると、人的リスク型の侵攻速度を下げられる。
7. 診療継続度と情報保護度を守りながら全5ウェーブの突破を目指す。

## 主な機能

- 4種の防御設備：メールフィルター／MFA／EDR／ネットワーク分離
- 3段階の設備強化と売却
- 5ウェーブの進行・スコアと勝敗判定
- 新規侵入ルート発生と突発的な人的リスク
- 職員教育（全体強化）
- 診療継続度の回復に役立つBCP
- 一時停止、2倍速、イベントログ
- PC・スマホ向けのレスポンシブUI

## 開発・実行

`index.html` に HTML / CSS / JavaScript をまとめてあります。外部ライブラリ、CDN、外部APIの呼び出し、個人情報の収集処理はありません。

Webサーバーから配信する場合は、通常の静的サイトとして `index.html` を公開してください。ブラウザで直接開くこともできます。

## 留意点

本作は**教育用のフィクション**です。ゲーム内の攻撃や対策の効果は単純化した設定であり、実際の侵入方法、院内ネットワーク構成、安全性、医療情報システムの基準適合性を表すものではありません。
